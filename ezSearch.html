Welcome to EZ Search!

Important

It is crucial to regularly export your data!

All your EZ Search bookmark data is stored directly in your browser's Local Storage.
This means if you clear your browser's cache, cookies, or site data, your bookmarks will be permanently deleted.

This is a Chrome Extension designed to help you easily manage your bookmarks. You can export your current Chrome bookmarks, and import them to the extension. Be sure to set a keyboard shortcut by going to "Extensions" > "Manage Extensions" > "Keyboard Shortcuts". (Recommended to use "Ctrl+Shift+F".)

How to Export/Import:

  • Export: Click the Export button at the top.
    • This will download a .json file containing all your bookmarks.
    • Keep this file safe as a backup.
  • Import: Click the Import button at the top.
    • You can choose to import both:
      • EZ Search JSON Files - Exported from this app.
      • Google Chrome HTML Bookmarks - Exported directly from Chrome's Bookmark Manager.
    • (Duplicate URLs will be skipped during import.)

Other Features:

  • Keyboard Shortcuts:
    • Ctrl + Shift + F — Launch EZ Search
    • Esc — Close pop-ups, clear search bar, return focus from link to search bar
    • ↑ / ↓ — Navigate between visible links
    • Enter — Open focused link (or first result if search bar is active) in current tab
    • Ctrl + Enter — Open focused link (or first result if search bar is active) in new background tab
    • Ctrl + Shift + Enter — Open focused link (or first result if search bar is active) in new tab

Other Features:

  • Add New Link: Use the "Add New Link" section to quickly add new bookmarks with a title, URL, and optional tags.
    • Advanced options allow for custom favicon URLs or Base64 encoded favicons.
  • Search: Use the search bar to filter your bookmarks by title, URL, or tags.
    • You can type multiple keywords, and the search will match links containing all of them.
  • Tags: Assign tags to your links for better organization.
    • Click on any tag pill to quickly add/remove it in the search bar, helping you filter by tags.
  • Edit/Delete: Each link card has Edit and Delete buttons for easy management.
  • Drag & Drop: Reorder your links by dragging and dropping them into your preferred order.
  • Dark Mode: Toggle between light and dark themes using the moon/sun icon ( / ) at the top.
